┌──────────────────────────────────────────────────────────────────────────────┐
│ STEP 1: UPLOAD FILES TO YOUR VM                                             │
└──────────────────────────────────────────────────────────────────────────────┘

From your LOCAL MACHINE (replace YOUR_VM and YOUR_ZONE):

  gcloud compute scp scripts/*.sh YOUR_VM:/home/mindlift/mindlift/scripts/ --zone=YOUR_ZONE
  
  gcloud compute scp webapp/chatbot/management/commands/auto_train_models.py YOUR_VM:/home/mindlift/mindlift/webapp/chatbot/management/commands/ --zone=YOUR_ZONE

┌──────────────────────────────────────────────────────────────────────────────┐
│ STEP 2: SSH INTO VM                                                         │
└──────────────────────────────────────────────────────────────────────────────┘

  gcloud compute ssh YOUR_VM --zone=YOUR_ZONE
  sudo su - mindlift

┌──────────────────────────────────────────────────────────────────────────────┐
│ STEP 3: RUN SETUP                                                           │
└──────────────────────────────────────────────────────────────────────────────┘

  chmod +x /home/mindlift/mindlift/scripts/*.sh
  bash /home/mindlift/mindlift/scripts/setup_cron.sh

┌──────────────────────────────────────────────────────────────────────────────┐
│ STEP 4: VERIFY                                                              │
└──────────────────────────────────────────────────────────────────────────────┘

  bash /home/mindlift/mindlift/scripts/check_training_status.sh

┌──────────────────────────────────────────────────────────────────────────────┐
│ ✅ DONE! TRAINING WILL RUN AUTOMATICALLY                                    │
└──────────────────────────────────────────────────────────────────────────────┘

  • Schedule: Daily at 3:00 AM
  • Requires: 50+ user messages
  • Trains: 3 ML models (sentiment, themes, distortions)
  • Logs: /home/mindlift/mindlift/logs/auto_training.log

┌──────────────────────────────────────────────────────────────────────────────┐
│ 📋 USEFUL COMMANDS                                                          │
└──────────────────────────────────────────────────────────────────────────────┘

  # Check status anytime
  bash /home/mindlift/mindlift/scripts/check_training_status.sh

  # View logs
  tail -f /home/mindlift/mindlift/logs/auto_training.log

  # Manual training
  cd /home/mindlift/mindlift/webapp
  source ../venv/bin/activate
  python manage.py auto_train_models

  # Force training (ignore data requirements)
  python manage.py auto_train_models --force

  # List cron jobs
  crontab -l

  # Edit training schedule
  crontab -e

┌──────────────────────────────────────────────────────────────────────────────┐
│ 🐛 TROUBLESHOOTING                                                          │
└──────────────────────────────────────────────────────────────────────────────┘

  Problem: Training not running
  Solution: Check cron: crontab -l | grep training
           Check logs: tail -f logs/auto_training.log

  Problem: Insufficient data
  Solution: Lower threshold: python manage.py auto_train_models --min-messages 20 --force

  Problem: Permission denied
  Solution: Fix ownership: sudo chown -R mindlift:mindlift /home/mindlift/mindlift
